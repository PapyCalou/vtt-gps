# VTT-GPS

Application web personnelle pour gérer des traces GPS de VTT, gravel, route et randonnée.

- Import de fichiers GPX (Garmin Connect, Strava, amis, sites spécialisés)
- Carte de toutes les sorties, fiche détaillée avec profil altimétrique
- Classement par type, secteur, distance, dénivelé, durée et difficulté
- Export GPX et partage vers Garmin Connect (Edge, Epix) ou OsmAnd
- Fiches vélo, vélo par défaut par pratique, carnet d'entretien
- Synchronisation facultative entre appareils via un dépôt GitHub privé

Les traces ne sont pas stockées dans ce dépôt : elles restent sur l'appareil,
et dans le dépôt privé choisi pour la synchronisation.

Cartographie : Leaflet, données © contributeurs OpenStreetMap, fonds OpenTopoMap, CyclOSM et IGN.
